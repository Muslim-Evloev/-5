# Social Network API

Учебный проект бэкенда социальной сети на NestJS с использованием гибридной архитектуры баз данных.

## Обоснование выбора баз данных (PostgreSQL + MongoDB)

В проекте используются две разные базы данных под разные задачи:
- **PostgreSQL (TypeORM)** хранит пользователей (`users`) и посты (`posts`). Эти данные имеют строгую структуру и требуют реляционных связей (внешний ключ `authorId` с каскадным удалением).
- **MongoDB (Mongoose)** хранит комментарии (`comments`). Комментарии — это большой поток однотипных записей с гибкой схемой (в будущем в документ комментария легко добавить реакции, вложенные ответы или историю правок без миграций таблиц). Кроме того, для чтения комментариев не нужны сложные SQL-объединения (`JOIN`).

## Переменные окружения и запуск

1. Создайте файл `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   ```
   Обязательно убедитесь, что заполнена переменная `MONGODB_URI` (по умолчанию `mongodb://localhost:27017/social-network`).

2. Запустите базы данных (PostgreSQL и MongoDB) в Docker:
   ```bash
   docker-compose up -d
   ```

3. Установите зависимости и запустите приложение:
   ```bash
   npm install
   npm run start:dev
   ```

Документация Swagger будет доступна по адресу: `http://localhost:3000/docs`.
